# 05_design_history 追記用テンプレート

以下を `05_design_history.md` の既存DHフォーマットに合わせて整理して。

目的は、貼り付けた議論内容を、05へそのまま追記できる設計履歴として整形すること。
議論文をそのままコピーするのではなく、既存のDH形式に合わせて、背景・議論・現時点の考え・決定事項・保留事項・根拠・実装引き継ぎ・次回検討へ整理して。

日時: 2026-07-03 15:20 JST
DH番号: 次の連番
テーマ: （ここにテーマ）

議論内容:
（ここに壁打ち内容を貼る）

出力要件:
- Markdownブロックで出す
- 05へそのまま追記できる形
- 以下の見出し構成に合わせる
  - `---`
  - `## DH-<DH番号> / <日時>`
  - `### テーマ`
  - `### 背景`
  - `### 議論`
  - `### 現時点の考え`
  - `### 決定事項`
  - `### 保留事項`
  - `### 根拠`
  - `### 実装引き継ぎ`
  - `### 次回検討`
  - `---`
- 決定事項と保留事項を分ける
- 決定事項は、議論内容の中で明確に決定・採用・方針化されたものだけを書く
- 保留事項は、未決・要確認・後続確認・判断待ちのものだけを書く
- 推測で補完しない
- 次に03へ反映すべき決定事項が分かるようにする
- `### 実装引き継ぎ` には、03へ同期後に実装者が再協議せず使う前提・実装時に確認すべき資料・不足入力として扱う条件を書く
- 03へ同期された決定事項は「未決定」と扱わない前提を書く

出力フォーマット:

```markdown
---

## DH-<DH番号> / <日時>

### テーマ
<テーマ>

### 背景
<なぜこの議論をしたか。議論内容から分かる範囲だけで整理する。>

### 議論
- <議論された内容を箇条書きで整理する>
- <候補案・比較・懸念点はここに書く>
- <ただし推測で補完しない>

### 現時点の考え
<議論の結果として、現時点でどう考えるかを自然文で整理する。未決なら未決と書く。>

### 決定事項
- <採用済みの決定事項だけを書く>
- <03_decisions.md へ反映すべき内容が分かる粒度で書く>

### 保留事項
- <未決・要確認・後続確認の事項を書く>
- <なければ「なし」と書く>

### 根拠
- <決定事項の理由を書く>
- <議論内容から分かる根拠だけを書く>

### 実装引き継ぎ
- <03_decisions.md へ同期後、実装者が決定済みとして扱う前提を書く>
- <実装時に参照すべき資料・仕様・DDL・seedなどを書く>
- <03_decisions.md にある決定事項は再協議せず、不足がある場合のみ不足入力として報告する旨を書く>

### 次回検討
- <次に確認・反映・協議することを書く>
- <03_decisions.md へ反映が必要な場合は明記する>

---
```
