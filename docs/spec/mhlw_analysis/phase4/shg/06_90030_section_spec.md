## ■ セクション概要

90030 は、指導初回情報セクションである。
本セクションには、初回面接実施情報および保健指導計画情報が含まれる。

また、本セクションは以下を含む。

- 人が解釈するための説明ブロック（`text`）
- 機械可読表現である `entry` 要素

## ■ セクションの位置付け（重要）
- 90020 は初回面接を分割実施した場合にのみ出現する
- 90030 は指導初回情報セクションとして、分割実施の有無にかかわらず初回側の基本セクションとして扱う
- 初回面接を分割実施した場合、90020 には初回面接①実施情報が入り、90030 には初回面接②実施情報および保健指導計画情報が入る
- 初回面接を分割実施しない場合、90030 には初回面接実施情報および保健指導計画情報が入る
- 本ファイルでは、まず `fuzoku3.csv` で FIX した保健指導計画情報側（1331〜1345）を主対象として整理する
- サンプル XML では、分割実施時に 90020（初回面接①）と 90030（初回面接②＋計画）が同一 XML 内に併存する構造を確認できる
- このサンプル構造から、分割実施時の初回報告は①のみの途中状態ではなく、②実施後に初回面接全体が揃った時点で作成される構成として扱う
- よって、①から②への途中変更差分そのものを報告するのではなく、初回報告時点の確定内容を報告する構造として扱う

## ■ セクション部仕様

5-1A の 90030 セクション定義および付属3の構造定義に従い、90030 は section コード `90030` を持つ指導初回情報セクションとして扱う。

想定される section の骨格は以下の通り。

```xml
<section>
  <code code="90030" codeSystem="1.2.392.200119.6.1010"/>
  <text/>
  ...
</section>
```

---

## ■ エントリ部仕様（付属3ベース）

5-1A の 90030 エントリ部仕様および付属3に基づき、90030 セクションの entry 配下には、初回面接実施情報および保健指導計画情報を表す act / observation 群が配置される。本ファイルでは保健指導計画情報側を主対象として整理する。

- 目標系項目（1332〜1338）は、計画値として扱う
- `fuzoku3.csv` 上では、1332〜1338 は `INT / OBS / GOL` の組で整理されている
- 1331, 1339〜1345 は `INT / OBS / INT` の組で整理されている
- 値型は項目に応じて `PQ` / `CD` / `INT` を使い分ける
- 単位付き項目では `cm` / `kg` / `mm[Hg]` / `kcal` / `wk` が使われる

XPath は section 構造の事実参照用として保持する方針とし、必要に応じて別途整理する。

## ■ このファイルで固定する事実

- 90030 は指導初回情報セクションである
- 90030 には初回面接実施情報の entry と保健指導計画情報の entry が含まれる
- 初回面接実施情報側は `act moodCode="EVN"`、保健指導計画情報側は `act moodCode="INT"` として整理する
- 90030 は分割実施の有無にかかわらず、初回側の基本セクションとして扱う
- 初回面接を分割実施した場合、90020 は初回面接①、90030 は初回面接②および保健指導計画情報を扱う
- 初回面接を分割実施しない場合、90030 は初回面接実施情報および保健指導計画情報を扱う
- 本ファイルでは 1331〜1345 を保健指導計画情報側の対象項目として整理する
- 項目単位の条件・型は `fuzoku3.csv` 側で FIX 済みである
- 1332〜1338 は計画値項目として整理され、サンプル上も `GOL` を用いる
- 1331, 1339〜1345 は `INT / OBS / INT` の組で整理され、サンプル上も `INT` を確認できる
- サンプル上、90030 側の初回面接実施情報には 1303 / 1304 / 1306 が配置されている
- 5-1A 3.3.4.2 により、90030 の初回面接実施情報エントリ仕様は表21を基本としつつ 1303 が追加される構造であるため、1301 / 1302 / 1305 も 90030 側の初回面接実施情報に含まれるものとして扱う
- 出現条件は section 単位ではなく項目単位で管理する（ただし 90030 自体は初回側の基本セクションとして扱う）
