## ■ セクション概要

90030 は、保健指導計画情報を記述するセクションである。
主に、継続的支援予定期間、目標値、生活習慣改善計画、計画上のポイント等を扱う。

また、本セクションは以下を含む。

- 人が解釈するための説明ブロック（`text`）
- 機械可読表現である `entry` 要素

※ classCode / moodCode は entry 配下の act / observation に対する属性として扱う（section そのものの属性ではない）。

## ■ セクション部仕様

5-1A の 90030 セクション定義および付属3の構造定義に従い、90030 は section コード `90030` を持つ保健指導計画情報セクションとして扱う。

想定される section の骨格は以下の通り。

```xml
<section>
  <code code="90030" codeSystem="1.2.392.200119.6.1010"/>
  <text/>
  ...
</section>
```

---

## ■ エントリ部仕様（付属3ベース）

5-1A の 90030 エントリ部仕様および付属3に基づき、90030 セクションの entry 配下には、計画情報を表す act / observation 群が配置される。

- 目標系項目（1332〜1338）は、計画値として扱う
- `fuzoku3.csv` 上では、1332〜1338 は `INT / OBS / GOL` の組で整理されている
- 1331, 1339〜1345 は `INT / OBS / INT` の組で整理されている
- 値型は項目に応じて `PQ` / `CD` / `INT` を使い分ける
- 単位付き項目では `cm` / `kg` / `mm[Hg]` / `kcal` / `wk` が使われる

XPath は section 構造の事実参照用として保持する方針とし、必要に応じて別途整理する。

## ■ このファイルで固定する事実

- 90030 は保健指導計画情報セクションである
- `entry` は 1..1（内部に複数 observation を含む）
- 1331〜1345 を 90030 の対象項目とする
- 項目単位の条件・型は `fuzoku3.csv` 側で FIX 済みである
- 1332〜1338 は計画値項目として整理され、`GOL` を用いる
- 1331, 1339〜1345 は `INT / OBS / INT` の組で整理される
- 出現条件は項目単位で管理する（section 単位では固定しない）
