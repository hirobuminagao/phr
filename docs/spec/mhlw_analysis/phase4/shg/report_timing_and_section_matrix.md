# report_timing_and_section_matrix（SHG）

## ■ 目的

本ファイルは、厚生労働省仕様書（特定保健指導XML）における

- 報告タイミング
- report_code
- CDA section の組み合わせ

を整理し、**辞書として参照できる形にすること**を目的とする。

※ 本フェーズは設計ではなく、仕様の前提整理（辞書化）である

---

## ■ 前提

- 一次情報は厚生労働省PDF（仕様書）
- 本ファイルはその内容を分解・再構成したもの
- 実装ロジックの定義は目的ではない
- 解釈の揺れを防ぐため、仕様を固定することが目的

---

## ■ 作業ルール（FIX管理）

本フェーズにおける作業ブレ防止のため、以下を厳守する：

- 一度FIXした項目は再度チェック対象に戻さない
- 差分チェックは未FIX範囲のみに対して実施する
- 画面表示やgrep結果で再出現しても「未FIX扱い」にしない
- FIX範囲は明示的に管理し、暗黙に戻らない
- 再チェックは「明示的なやり直し指示」があった場合のみ行う

👉 FIXは「確定状態」であり、途中状態ではない

---

## ■ 構造の考え方（重要）

本仕様は以下の関係で成立する：

```
報告タイミング
    ↓
使用される section
    ↓
report_code が決まる
```

👉 report_code は主ではなく結果である
