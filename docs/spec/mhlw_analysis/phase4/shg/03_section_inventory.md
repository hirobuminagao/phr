

# 03 Section Inventory

## 1. 目的

本ドキュメントは、特定保健指導（SHG）XML の CDA セクション一覧と、その役割の目録を整理するための spec である。

目的は以下の2点。

- SHG XML に出現する section を一覧化し、個別 spec へ迷わず分解できるようにする
- 90010 / 90020 / 90030 などの section が、それぞれ何を担当するかを先に俯瞰できるようにする

---

## 2. 対象範囲

- 特定保健指導 XML の CDA section
- 90010 / 90020 / 90030 / 90040 / 90050 / 90060 / 90090

## 4. section の位置付け

```yaml
ClinicalDocument:
  component:
    structuredBody:
      component:
        section:
```

- section は SHG XML のボディ部を構成する意味単位である
- header 管理情報（recordTarget / participant / documentationOf など）とは別レイヤーで扱う
- 各 section は `code` により識別され、`entry` に実データを持つ

---

## 6. 優先して読むべき section

優先順は以下とする。

1. 90010
2. 90020
3. 90030
4. 90060
5. 90040 / 90050
6. 90090

理由:
- 90010 / 90020 / 90030 は初回系の理解に直結する
- 90060 は outcome / 評価結果と直結する
- 90040 / 90050 は支援実績の明細・集計に関わる
- 90090 は指導機関情報として独立性が高い

---

## 7. section 間の関係（概要）

```yaml
flow:
  90010:
    - 共通情報

  90020:
    - 初回①

  90030:
    - 初回面接 / 計画 / 目標

  90040:
    - 支援集計

  90050:
    - 継続支援明細

  90060:
    - 中間評価 / 最終評価

  90090:
    - 指導機関情報
```

- 90010 は全体の共通情報に近い
- 90020 / 90030 は初回に属する
- 90050 は継続支援の詳細、90040 はその集計寄りと考える
- 90060 は最終的な評価・成果の整理に関わる
