## ■ この突合メモから 06 に反映した要点

- `90030` は「指導初回情報セクション」であり、計画情報だけのセクションではない
- `90020` は分割時のみ出現し、`90030` は初回側の基本セクションである
- 分割時は `90020 = 初回面接①`、`90030 = 初回面接② + 保健指導計画情報`
- 分割実施時の初回報告は、①のみの途中状態ではなく、②実施後の確定内容を報告する構造として扱う
- `90030` には初回面接実施情報 entry と保健指導計画情報 entry の2つがある
- `1303` は `90020` ではなく `90030` に置く
- `1301 / 1302 / 1305` も 90030 側の初回面接実施情報に含まれるものとして扱う
- `text` は主対象ではなく、伝送実体は `entry` 側とする
