## ■ セクション概要

90080 は、**指導機関情報**を記述するセクションである。

本セクションは、保健指導を実施した機関について、機関番号・機関名・主対応内容・実施内容を保持する。

また、本セクションは同一構造を繰り返す形で、複数回分の指導機関情報を表現する。

※ 付属3および `fuzoku3.csv` では、(1)〜(8) の形式で整理されているが、これは資料上の表現単位であり、同型の機関情報ブロックが繰り返される構造として読む。

### ■ NOTE（列挙単位に関する解釈）

- 指導機関の列挙単位（同一機関の扱い）は資料上明示されていない
- 機関番号に加えて主対応内容・実施内容を保持していることから、単純な機関一覧ではなく役割単位での記録である可能性がある
- 同一機関を統合するか、主対応内容・実施内容単位で分割するかは未確定であり、実装依存となる可能性がある
- 本仕様では当該点を未確定事項として扱い、事実確認後に整理する

### ■ 事実確認時の更新ポイント

後日、PDF・付属3・XMLサンプル・実装確認などにより事実を再確認した場合は、以下の観点で更新箇所を切り分ける。

- **親資料・参照箇所の誤り**
  - 更新箇所：`## ■ 親資料と参照資料` / `### ■ 主な参照箇所（5-1A）`
  - 例：章番号、表番号、親資料名、付属資料の位置付け

- **項目コード・項目名・値型・出現条件の誤り**
  - 更新箇所：`## ■ 項目対応（付属3 / fuzoku3 ベース）`
  - 例：1811〜1884 の項目コード、INT/ST/CD、legal_report 条件

- **section / entry / act / observation の構造事実の誤り**
  - 更新箇所：`## ■ セクション部仕様` / `## ■ エントリ部仕様（付属3ベース）`
  - 例：entry の持ち方、繰り返しブロックの表現、ネスト構造、XML例

- **本ファイル内の説明用整理の見直し**
  - 更新箇所：`## ■ セクション概要` / `## ■ エントリ部仕様（付属3ベース）` / `## ■ このファイルで固定する事実`
  - 例：「機関番号 / 機関名 / 対応区分 / 実施区分」の分類、説明文の粒度、注意書き

- **未確定事項が確定した場合**
  - 更新箇所：`## ■ 留保事項`
  - 例：XMLサンプル確認結果、textブロック順、繰り返し構造の表現方法
