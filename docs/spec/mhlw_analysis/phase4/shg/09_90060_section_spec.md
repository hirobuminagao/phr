## ■ セクション概要

90060 は、保健指導の**実績評価情報（最終評価）**を記述するセクションである。

本セクションは、支援の結果としてのアウトカム（腹囲・体重・生活習慣改善など）を評価コードとして保持する。

また、90060 は単なるアウトカム結果の列挙ではなく、**最終評価としての総括的意味を持つセクション**であり、以下の性質を持つ。

- 計画（90030）と実績（90040）を踏まえた結果評価である
- 評価は「達成 / 未達成 / 評価不能 / 該当なし（喫煙なし）」などの状態をコードで表現する
- 各評価項目は独立して存在するが、全体としては保健指導の成果を示す

また、本セクションは以下を含む。

- 人が解釈するための説明ブロック（`text`）
- 機械可読表現である `entry` 要素

※ classCode / moodCode は entry 配下の act / observation に対する属性として扱う（section そのものの属性ではない）。

## ■ セクション部仕様

付属3のセクション定義に従い、90060 は section コード `90060` を持つ実績評価セクションとして扱う。

```xml
<section>
  <code code="90060" codeSystem="1.2.392.200119.6.1010"/>
  <text/>
  ...
</section>
```

---

## ■ エントリ部仕様（付属3ベース）

90060 の entry 配下は、以下の4区分で構成される。

### ① プロセス（評価実施情報）

- 実施日（TS）
- 実施方法（CD）
- 実施者（ST）
- 評価不能時の確認回数（INT）

👉 「どのように評価したか」を表す

---

### ② 実測値（評価時点データ）

- 腹囲・体重・血圧など（PQ）

👉 アウトカム評価の根拠となる実測値

---

### ③ アウトカム（改善結果）

- 腹囲・体重改善（24090）
- 生活習慣改善（24100）

👉 すべて CD（コード値）で表現する

### 値の詳細（評価コード体系）

アウトカム項目で使用するコード値は、以下の体系に従う。

#### 24090系（腹囲・体重の改善）

- 0：未達成
- 1：1cm・1kg 改善あり
- 2：2cm・2kg 改善あり

※ 計画なし（9）は公式仕様に存在しないため、運用上は 0（未達成）として扱う

#### 24100系（生活習慣の改善）

- 0：改善なし（未達成）
- 1：改善あり（達成）
- 8：喫煙なし（喫煙習慣のみ特例）
- 9：評価不能／目標なし

※ 本コード体系は「24100コード早見表」と一致させること

---

### ④ 集計（アウトカム合計）

- 1615（アウトカム評価の合計）

👉 プロセス合計（1742）や総合ポイント（1743）は本セクションには含まれない

---

### XML例（アウトカム）

```xml
<entry>
  <observation classCode="OBS" moodCode="EVN">
    <code code="1022001001"/>
    <value xsi:type="CD" code="1"/>
  </observation>
</entry>
```

---

### 設計上の注意

- セクション全体としては複数型（TS / PQ / CD / INT / ST）が混在する
- アウトカムのみ CD であり、他はそれぞれ適切な型を使用する
- 90060 は「最終評価のパッケージ」であり、単一型セクションではない

## ■ 出現条件

90060 セクションは以下のタイミングで出現する。

- **second_claim（最終評価時）**
- `legal_report` にも出現

※ first_claim では出現しない
