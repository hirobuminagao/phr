## ■ セクション概要

90050 は、**中間評価情報**を記述するセクションである。

本セクションは、継続的支援の途中段階における評価として、評価実施情報・実測値・改善状況・補足情報を保持する。

また、本セクションは以下を含む。

- 人が解釈するための説明ブロック（`text`）
- 機械可読表現である `entry` 要素

※ classCode / moodCode は entry 配下の act / observation に対する属性として扱う（section そのものの属性ではない）。

---

## ■ エントリ部仕様（付属3ベース）

90050 の entry 配下は、以下の4区分で構成される。

### ① プロセス（評価実施情報）

- 1501：中間評価の実施日付（TS）
- 1502：中間評価の支援形態（CD）
- 1503：中間評価の実施時間（PQ）
- 1504：中間評価の実施ポイント（INT）
- 1505：中間評価の実施者（CD）

👉 「どのように中間評価を行ったか」を表す

---

### ② 実測値（評価時点データ）

- 1506：腹囲
- 1507：体重
- 1508：収縮期血圧
- 1509：拡張期血圧
- 値型は `PQ`

👉 中間評価時点の測定値を表す

---

### ③ アウトカム（改善結果）

- 1510：腹囲・体重の改善（24090）
- 1511〜1515：生活習慣の改善（24100系）
- 値型は `CD`

👉 改善状況を意味付きコードで表現する

### 値の詳細（評価コード体系）

アウトカム項目で使用するコード値は、以下の体系に従う。

#### 24090系（腹囲・体重の改善）

- 0：未達成
- 1：1cm・1kg 改善あり
- 2：2cm・2kg 改善あり

#### 24100系（生活習慣の改善）

- 0：改善なし（未達成）
- 1：改善あり（達成）
- 8：喫煙なし（喫煙習慣のみ特例）
- 9：評価不能／目標なし

※ 本コード体系は「24100コード早見表」と一致させること。

---

### ④ 補足

- 1516：中間評価情報（ST）

👉 中間評価に関する自由記載・補足情報を表す

---

### 設計上の注意

- 90050 は「中間評価時点」の評価情報であり、最終評価そのものではない
- セクション全体としては複数型（TS / PQ / CD / INT / ST）が混在する
- アウトカムのみ CD であり、他はそれぞれ適切な型を使用する
- 1516 は補足情報であり、アウトカム合計や総合ポイントを表す項目ではない

---

## ■ 出現条件

`fuzoku3.csv` で FIX した結果に基づくと、90050 セクションの出現条件は項目単位で整理される。

### 1. second_claim に出現する項目

- 1501〜1516

### 2. support_type による差分

- active：主に `△`
- motivational / motivational_equivalent：`▲*` または `▲` を含む

※ 付属3 / `fuzoku3.csv` 上では、active と motivational 系で requirement_symbol に差があるため、実装時は section 単位ではなく項目単位で条件を参照する。

---

## ■ このファイルで固定する事実

- 90050 は中間評価情報セクションである
- 1501〜1516 を対象項目とする
- プロセス・実測値・アウトカム・補足の4区分で構成される
- アウトカムは CD、実測値は PQ、プロセスは TS / CD / PQ / INT、補足は ST を使用する
- 出現は second_claim を前提とし、support_type に応じて requirement_symbol が変動する
