## ■ セクション概要

90070 は、**保健指導計画に基づく集計情報**を記述するセクションである。

本セクションは、継続的支援の予定回数・予定時間・計画上のポイントなど、計画段階での数量的な集計情報を保持する。

また、本セクションは以下を含む。

- 人が解釈するための説明ブロック（`text`）
- 機械可読表現である `entry` 要素

※ classCode / moodCode は entry 配下の act / observation に対する属性として扱う（section そのものの属性ではない）。

---

## ■ セクション部仕様

5-1A の 90070 セクション定義および付属3の構造定義に従い、90070 は section コード `90070` を持つ計画上の集計情報セクションとして扱う。

```xml

  <code code="90070" codeSystem="1.2.392.200119.6.1010"/>
  <text/>
  ...
</section>
```

## ■ エントリ部仕様（付属3ベース）

90070 の entry 配下は、計画上の集計 observation 群で構成される。

※ 以下の「回数系 / 時間系 / 集計系」の区分は、付属3の原文区分ではなく、本ファイルでの説明用整理である。

### ① 回数系

- 1701 / 1703 / 1705 / 1707 / 1709 / 1711
- 値型は `INT`

👉 各支援形態ごとの予定回数を表す

---

### ② 時間系

- 1702 / 1704 / 1706 / 1708 / 1710
- 値型は `PQ`

👉 各支援形態ごとの予定合計時間を表す

---

### ③ 集計系

- 1712：計画上の継続的な支援によるポイント(合計)
- 1713：計画上のポイント(合計)
- 値型は `INT`

👉 1712 は継続的支援由来の集計、1713 は計画全体の総合集計を表す

---

### 設計上の注意

- 90070 は「計画時点」の集計情報であり、実施結果や最終評価ではない
- 回数系は `INT`、時間系は `PQ`、集計系は `INT` を使用する
- 同じ「ポイント」でも、1712 と 1713 は意味が異なるため混同しない
