# サンプルXML一覧（特定保健指導 / 健診）

本ディレクトリは、厚生労働省および関連機関（例：社会保険診療報酬支払基金）が公開している
特定保健指導・特定健診XMLのサンプルを保管する。

---

## ■ 目的

本サンプルは以下の用途で利用する。

- PDF仕様書との構造差分確認
- XPath検証（section / entry / observation 構造）
- report_codeごとの構造差分確認
- 出現条件（必須 / 条件付き）の実例確認
- 実装時のデバッグ・再現用データ

---

## ■ 前提ポリシー

- サンプルXMLは**仕様の完全な実装例ではない**
- 出現しない項目は「未出現」であり「存在しない」ことを意味しない
- 正式仕様の一次情報は以下とする
  - 厚生労働省PDF（CDA仕様書）
  - 付属資料（付属3 等）

---

## ■ ディレクトリ方針

本ディレクトリは「共通参照用」とする。

- shg（特定保健指導）専用ではない
- header / section / report_code 横断で参照する

---

## ■ サンプル一覧

| ファイル名 | 出典 | 用途 | 備考 |
|------------|------|------|------|
| (例) shg_fund_sample.xml | 支払基金 | 構造確認 | 初回 or 最終などを後で記載 |

---

## ■ 運用ルール

- 新しいサンプルを追加した場合は本READMEに追記する
- ファイル名は以下ルールを推奨

```
<domain>_<source>_<pattern>.xml
```

例：

```
shg_fund_initial.xml
shg_fund_final.xml
```

---

## ■ 今回の設計上の位置づけ

本ディレクトリは以下の三層のうち「実例層」に該当する。

```
PDF仕様      → ルール
付属資料     → 項目定義
サンプルXML  → 実例（本ディレクトリ）
```

この3つを組み合わせて仕様を解釈・実装する。
