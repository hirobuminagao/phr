# 01 File Archive Spec

## 1. 目的

本仕様は、特定健診・特定保健指導データの電子的交換において、
提出に必要な一連のファイルのフォルダ構成、およびファイル名の仕様を定めるものである。

本仕様では以下を対象とする：
- 送付用ファイルの格納体系および配置体系
- ファイル命名規則
- アーカイブ（ZIP）構成

## 2. 対象範囲

本仕様は以下を対象とする：

- 特定健診データ
- 特定保健指導データ
- 送付用ファイルアーカイブ（ZIP）
- アーカイブ内のフォルダ構成
- XMLファイル命名規則

本仕様は以下を対象外とする：

- XML本文（ClinicalDocument / section構造）
- 各検査項目・保健指導項目の定義（付属資料）

## 3. ルートフォルダ命名規則

送付用ファイルアーカイブのルートフォルダ名は、以下の要素で構成される。

[提出元機関番号]_[提出先機関番号]_[提出年月日(YYYYMMDD)][同日分割送信回数(N)]_[実施区分コード(X)]

### 各要素

| 要素 | 内容 |
|------|------|
| 提出元機関番号 | 8〜10桁 |
| 提出先機関番号 | 7〜10桁 |
| 提出年月日 | YYYYMMDD |
| 同日分割送信回数 | 1桁（初回は0） |
| 実施区分コード | 1桁 |

### 補足

- 同一日に複数回送信する場合、分割番号(N)を0,1,2...と増加させる（最大9）
- 保険者番号が8桁未満の場合の取り扱いは原本に明示されていないため、実装時には8桁固定となるようゼロ埋めする運用とする（原本外の実装方針）

### 参照元

- 厚生労働省「送付用ファイルアーカイブ仕様説明書 Ver.4」
- 8-1A.pdf 表2-1（ルートフォルダ命名規則）

## 4. ファイル命名規則

データファイルおよび決済情報ファイルは、以下の形式で命名する。

例：
h12345678992024052101000001.xml

### 構成

| 位置 | 内容 |
|------|------|
| 1 | 種別（h,c,g,p） |
| 2-11 | 機関番号 |
| 12-19 | 日付（YYYYMMDD） |
| 20 | 同日分割番号 |
| 21 | 実施区分コード |
| 22-27 | 連番 |
| 28- | 拡張子（.xml） |

### 補足

- データファイルと決済情報ファイルは1対1で対応する
- 先頭1文字のみ異なるファイル名となる

### 参照元

- 厚生労働省「送付用ファイルアーカイブ仕様説明書 Ver.4」
- 8-1A.pdf 表2-2（ファイル命名規則）

## note

### 異動者データ

保険者間の異動者データ提出においては、
ファイル命名規則は適用されず、任意の名称とすることができる。

### 個別契約

個別契約の場合、決済情報ファイルおよび決済情報集計ファイルは不要となる場合がある。

## 5. アーカイブ規則

送付用データはZIP形式で圧縮する。

圧縮ファイル名は以下とする：

<ルートフォルダ名>.zip

- ルートフォルダ単位で圧縮する
- ZIP内に余分な親ディレクトリを含めない

### 参照元

- 厚生労働省「送付用ファイルアーカイブ仕様説明書 Ver.4」
- 8-1A.pdf 2.3（アーカイブ規則）

各交換パターンにおけるファイル構成は、原本仕様の表に準拠する。
