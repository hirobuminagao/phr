# phase4 MHLW分析メモ

## 目的

このディレクトリは、厚生労働省が公開している第4期関連資料を、実装で参照しやすい形に分解・整理するための作業場所とする。

主な目的は以下の3つ。

- 送付用ファイルアーカイブ仕様を整理する
- 健診情報XML仕様を整理する
- 特定保健指導XML仕様を整理する

実装や個別スクリプト修正を先に進めるのではなく、まず厚労省資料を一次情報として整理し、その後に section 実装や check / fix ロジックへ落とし込む前提とする。

## ディレクトリ方針

phase4 配下は、以下の3系統で整理する。

- `common/`
  - 健診 / 特定保健指導のどちらにも共通する内容
  - 主に送付用ファイルアーカイブ仕様、共通ルール、資料目録など
- `health_examination/`
  - 健診情報XMLに関する分析メモとspec化メモ
- `shg/`
  - 特定保健指導XMLに関する分析メモとspec化メモ

進め方は以下を基本とする。

2. `common / health_examination / shg` のどこに属するかを決める

5. 最後に section 実装や check / fix ロジックへ反映する

## FIX管理ルール

phase4 配下の分析・spec整理では、作業の往復や再点検ループを避けるため、以下を固定ルールとする。

- 一度 FIX した範囲は、明示的なやり直し指示がない限り再チェック対象に戻さない
- 差分確認・不足確認は未FIX範囲のみに対して行う
- 画面表示・grep結果・一時的な抜粋で再登場しても、それだけで未FIX扱いに戻さない
- FIX 状態は「途中」ではなく「確定」として扱う
- 各フェーズでは、何を FIX 済みとするかを明示して進める

この README は、phase4 全体の作業方針を固定するための親文書として扱う。

## LLM / AnythingLLM 前提での設計方針

本ディレクトリは、人間向けのspec整理だけでなく、AnythingLLM等のRAG（Retrieval-Augmented Generation）基盤から参照されることを前提とする。

そのため、各specファイルは以下の方針で作成する。

- 1ファイル1責務とし、テーマを明確に分離する
- 用語は揺らさず固定し、必要に応じて用語定義を明示する
- 一次情報（厚労省資料）と、その参照元（PDF名・ページ・表番号）を明示する
- 「仕様上の事実」と「実装上の採用方針」を明確に分離する
- 推論や補完ではなく、あくまで一次情報ベースで記述する

また、AnythingLLMでの検索・回答精度を高めるため、以下も意識する。

- セクション単位で意味が完結するように記述する
- 見出し構造を安定させ、他ファイルと共通フォーマットを採用する
- 同義語（例：特定保健指導 / SHG）やコード体系の対応関係を明示する

この方針により、本ディレクトリは「人間が読むspec」であると同時に、「LLMが参照して回答可能な知識ベース」として機能することを目指す。
