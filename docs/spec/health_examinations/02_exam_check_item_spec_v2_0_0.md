

# 制度チェック項目仕様

Version: v2.0.0

---

## 1. 目的

本資料は、特定健診・法定健診の制度チェックで使用する項目仕様を定義する。

本仕様は `exam_check_results` の横持ち項目、制度チェックロジック、およびDDL・スクリプト実装の共通仕様とする。

---

## 2. 元資料

- `docs/mhlw/phase4_v08/001082795.xlsx`
- `docs/mhlw/phase4_v08/付属2整理001082795.xlsx`
- 対象シート：`付属2_制度整理`

本仕様は上記資料を本プロジェクト向けに整理したものであり、制度改定時は原本との差分を確認して更新する。

---

## 3. 並び順

制度チェック対象項目は以下の順序で管理する。

1. 区分番号（昇順）
2. 同一性項目コード（昇順）

この並びを `exam_check_results` の横持ちカラム順および仕様書の標準とする。

## 5. 設計方針

- 制度チェック対象は同一性項目コード単位で管理する。
- 検査方法、左右、裸眼・矯正などでは項目を分割しない。
- `exam_item_values` は実値を縦持ちで保持する。
- `exam_check_results` は制度チェック対象項目を横持ちで保持する。
- 項目ごとに `status` / `reason` を保持する。
- 法定健診・特定健診の総合判定は項目別判定とは別に保持する。

---

## 6. status の考え方

各制度チェック項目は `status` と `reason` により状態を表現する。

代表例

- 値あり
- 算出
- 代替
- 不足
- 不正

正式なステータスコードは実装時に別途定義する。

---

## 7. 更新ルール

制度改定・原本更新時は、本資料を更新したうえで、DDL・チェックロジック・スクリプトへの影響を確認する。
