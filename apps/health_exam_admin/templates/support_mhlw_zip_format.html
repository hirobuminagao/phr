ZIPの作り方

ZIPを開いた直下に、提出対象のフォルダまたはXMLファイルが見える状態にします。

推奨 提出単位のフォルダを選んでZIP化 フォルダの親や作業用ディレクトリを含めないようにします。
確認 ZIP直下に余計な階層を作らない Downloads、xml作成_出力履歴、日付フォルダなどが直下に入っていないか見ます。
避ける 作業ルートごとZIP化しない 受領フォルダ全体や履歴フォルダ全体をまとめると、提出先で読み取れない原因になります。

基本構造

ZIPの中を開いた時に、提出対象だけが見える形にします。

確認箇所 OK NG
ZIP直下 提出用フォルダ、またはXMLファイルが直接見える 作業フォルダ、Downloads、履歴フォルダが先に見える
ルートフォルダ 提出する単位のフォルダだけをルートにする 受領ルートや複数の関係ない健診機関フォルダを含める
対象ファイル XML作成で出力された提出対象ファイルだけを含める CSV、元XML、ログ、作業メモ、別日付の出力を混ぜる
再ZIP 解凍後に対象フォルダを選び直してZIP化する ZIPファイルを含むフォルダごとさらにZIP化する

例

FinderやエクスプローラーでZIPを開いた時の見え方です。

OK

提出フォルダを直接ZIP化

提出用.zip
└─ XML提出フォルダ
   ├─ XXXXX.xml
   └─ YYYYY.xml
NG

作業ルートごとZIP化

提出用.zip
└─ xml作成_出力履歴
   └─ 2026-08-27
      └─ XML提出フォルダ
         ├─ XXXXX.xml
         └─ YYYYY.xml
NG

ZIPの二重包み

提出用.zip
└─ 作業フォルダ
   └─ XML提出フォルダ.zip

提出前チェック

迷ったらZIPを一度開いて、直下の見え方を確認します。

  1. 作成したZIPを開く。
  2. 直下に作業用の親フォルダが入っていないか見る。
  3. 提出対象ではないCSV、ログ、メモ、古い出力が混ざっていないか見る。
  4. この画面のOK例と同じ階層なら提出候補にする。
  5. 不安な場合は「XML ZIPチェック」で中身を確認する。
