ルートフォルダ

ZIP直下には、厚生労働省フォーマットのルートフォルダを1つ置きます。XMLやXSDをZIP直下へ直接置かない形です。

推奨 ルートフォルダごとZIP化 ZIPを開いた直下に `健診機関コード_保険者番号_作成日+連番_1` のフォルダが見える状態にします。
確認 DATA / XSD / ix08を確認 ルートフォルダの中に `DATA`、`XSD`、`ix08_V08.xml` があることを確認します。
避ける 親フォルダを含めない `03_健診結果（アップロードデータ）`、日付フォルダ、作業フォルダをZIP直下に出さないようにします。

作成ルール

このシステムの出力では、ルートフォルダ名と個人XML名を次の規則で作ります。

項目 作り方 例
ルートフォルダ名 健診機関コード_保険者番号_作成日8桁+同日分割送信回数_実施区分 0110119070_06139463_202608270_1
ZIPファイル名 ルートフォルダ名に `.zip` を付ける 0110119070_06139463_202608270_1.zip
個人XML名 h + 健診機関コード + 作成日8桁 + 同日分割送信回数 + 種別 + 6桁連番 + .xml h01101190702026082701000001.xml
ix08 ルートフォルダ直下に `ix08_V08.xml` を置く 0110119070_06139463_202608270_1/ix08_V08.xml
構成項目 種類 桁数 このシステムでの扱い
提出元健診機関番号 健診機関コード 10桁 健診機関マスタのコードを使用します。
提出先保険者番号 保険者番号 8桁 出力対象者の保険者番号を使用します。
提出年月日 作成日 8桁 `YYYYMMDD` 形式です。
同日分割送信回数 同じ提出元・提出先・提出日の送信回数 1桁 `0` から `9`。初回は `0`、同日に分割・再送する場合は順に増やします。
実施区分 提出データの種類 1桁 今回のXML出力では、特定健診情報を表す `1` 固定です。
個人XMLの種別 個人XMLファイル名内のデータ種別 1桁 今回のXML出力では、実施区分と同じく `1` 固定です。
個人XMLの連番 ZIP内の個人XML順序 6桁 `000001` から始めて、ZIP内で重複しないようにします。

提出前チェック

迷ったらZIPを一度開いて、直下の見え方とルートフォルダ名を確認します。

  1. 作成したZIPを開く。
  2. ZIP直下に `健診機関コード_保険者番号_作成日+連番_1` のルートフォルダが1つだけあるか見る。
  3. ルートフォルダ直下に `DATA`、`XSD`、`ix08_V08.xml` があるか見る。
  4. `DATA` の中に個人XMLが入っているか見る。
  5. `03_健診結果（アップロードデータ）`、日付フォルダ、作業フォルダ、別ZIPが混ざっていないか見る。
  6. 不安な場合は「XML ZIPチェック」で構成を確認する。
